# How GardenEvents Works

A venue is registered inside a Garden claim managed by the host. Events are scheduled against that venue with a name, start time, duration, ticket price, and capacity.

Players select events by their title in the player-facing command flow. Each physical ticket is a paper item with the event name and hidden persistent identifiers for the event and ticket.

A player may own multiple tickets for the same event. Each ticket has its own record and can only be admitted once.

At event start, online ticket holders receive a Minecraft chime notification.

Hosts can reserve a quantity of tickets for giveaways. Event tickets can also be sold through the Garden sign-shop system.
