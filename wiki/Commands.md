# Commands

Typical event commands include:

- `/venue create`
- `/venue info`
- `/venue list`
- `/venue delete`
- `/event create`
- `/event list`
- `/event info <event title>`
- `/event buy <event title> [quantity]`
- `/event admit`
- `/event tickets <event title> <quantity>`
- `/event cancel <event title>`

Event title completion should be used instead of requiring players to type UUID prefixes.
